# Dune Dashboards

A collection of Dune Analytics SQL queries for on-chain monitoring dashboards.

## Dashboards

### 01 — Stablecoin Large Transfers
Tracks large USDT transfers on Ethereum: top transfers, daily trends, and top senders.

### 02 — DEX Market Structure
Analyzes DEX volume share, top trading pairs, and large swap ratio on Ethereum.

### 03 — OFAC Sanctioned Activity
Monitors activity related to OFAC-sanctioned addresses.

## Structure

Each dashboard folder contains numbered SQL queries (`q1_*.sql`, `q2_*.sql`, ...) corresponding to modules in the dashboard.
