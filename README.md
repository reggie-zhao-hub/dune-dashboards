# Dune Dashboards

A collection of Dune Analytics SQL queries for on-chain monitoring dashboards.

## 📊 Dashboards

| # | Dashboard | Description | Dune Link |
|---|-----------|-------------|-----------|
| 01 | Stablecoin Large Transfers | Tracks large USDT transfers on Ethereum: top transfers, daily trends, and top senders. | [View on Dune](https://dune.com/vx09/stablecoin-large-transfer-monitor) |
| 02 | DEX Market Structure | Analyzes DEX volume share, top trading pairs, and large swap ratio on Ethereum. | [View on Dune](https://dune.com/vx09/ethereum-dex-market-structure) |
| 03 | OFAC Sanctioned Activity | Monitors on-chain activity of OFAC-sanctioned Ethereum addresses (last 365 days). | [View on Dune](https://dune.com/vx09/sanctioned-ethereum-addresses-on-chain-activity-monitor-last-365-days) |

## 📁 Structure

Each dashboard folder contains numbered SQL queries (`q1_*.sql`, `q2_*.sql`, ...) corresponding to modules in the dashboard.
